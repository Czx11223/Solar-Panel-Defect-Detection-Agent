## 1 任务背景与范围

系统已完成阶段0–6（需求、算法、后端、前端、集成与部署文档）。本阶段编写完整系统测试报告，覆盖：

| 测试域 | 内容 |
|---|---|
| 功能测试 | 用户管理、图片上传校验、AI检测推理、结果展示、历史记录导出；正常 + 异常场景 |
| 性能测试 | 单图推理速度（≤200ms 验收线）、并发简单测试 |
| 兼容性测试 | Chrome / Firefox / Safari / Edge 浏览器测试清单 |
| 验收检查 | 对照任务书全部需求逐条验收清单 |
| 结论输出 | 测试结论、问题清单、优化建议 |

格式约束：测试报告为 Markdown（docs/test_report.md）。

## 3 docs/test_report.md 章节大纲

| 章节 | 内容要点 |
|---|---|
| 1 测试概述 | 测试对象、范围、方法（黑盒：接口级 + UI 级）、执行环境与时间、结论摘要 |
| 2 测试环境 | 硬件（CPU/内存，推理硬件按 D6）、软件版本（Python/Node/浏览器）、被测版本 |
| 3 功能测试 | 5 模块用例表（编号/前置/步骤/预期/优先级/结果）：用户管理、上传校验、检测推理、结果展示、历史导出；异常场景含 40001/40002/40003/40101/40102/40301/40401/40901/50301 全错误码覆盖 |
| 4 性能测试 | 4.1 推理速度（口径/验收线/方法，引用 export.py --benchmark 与 model_eval_report.md）；4.2 并发简单测试（脚本、指标、结果） |
| 5 兼容性测试 | 浏览器矩阵 × 功能点清单（登录/上传/检测/结果/历史/导出）+ 响应式（md 768 断点） |
| 6 验收检查清单 | 对照任务书逐条：任务书要求 → 验收标准 → 测试方法 → 结果（依据 checklist.md A/B 表） |
| 7 问题清单 | 已发现问题（含环境性：权重缺失）、遗留问题（真实模型指标、生产部署） |
| 8 测试结论 | 分项结论 + 整体结论（是否满足验收线） |
| 9 优化建议 | 模型迭代、并发与性能、安全、兼容性补测等 |

## 4 功能测试用例设计要点

| 模块 | 正常场景 | 异常场景（错误码） |
|---|---|---|
| 用户管理 | 注册成功、登录成功、查看/修改资料、修改密码后旧密码失效 | 重名 40901、邮箱非法 40001、弱密码 40001、密码错 40102、原密码错 40102、未登录 40101 |
| 图片上传校验 | jpg/jpeg/png/bmp 四种格式正常上传 | 超 10MB 40002、假扩展名 40003、坏扩展名 40003、损坏图像 40001 |
| AI检测推理 | 全链路返回 record_id/targets/defect_summary/advice/标注图 base64/结果图 URL | 模型未就绪 50301 |
| 结果展示 | 标注框与置信度渲染、运维建议三档、免责声明展示（前端） | — |
| 历史记录导出 | 列表分页倒序、详情、原图/结果图访问、CSV 导出（utf-8-sig） | 越权访问他人记录 40301/图像 404、记录不存在 40401 |

现有 18 冒烟用例已覆盖上述大部分接口级场景，报告中作为"已验证"证据引用；前端页面流 8 E2E 用例作为 UI 层证据引用。

## 5 性能测试设计要点

| 测试项 | 方法 | 验收线 | 数据来源 |
|---|---|---|---|
| 单图推理耗时 | export.py --benchmark：letterbox+推理+NMS，CPU onnxruntime，预热后多次取均值 | ≤200ms | model_eval_report.md（待真实模型） |
| 并发简单测试 | 轻量 Python 脚本：多线程并发请求（登录/列表/检测），统计成功率、平均/最大响应时间、错误率 | 无硬性验收线，参考基线 | 报告内实测（检测接口受权重缺失影响时标注） |

## 6 兼容性测试清单要点

浏览器矩阵（最新两版本）× 核心功能：登录注册、图片上传与校验提示、检测结果展示、历史列表与详情、CSV 导出、响应式布局（PC/移动 768px 断点）。输出为执行清单，含执行状态列。
