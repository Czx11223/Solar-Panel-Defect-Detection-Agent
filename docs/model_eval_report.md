## 8 模型局限性与免责声明

1. **适用范围**：本模型基于可见光RGB图像训练，仅识别六类面板状态（清洁、积灰、鸟粪、电损伤、
   物理损伤、积雪）；类别范围外的缺陷（如热斑、隐裂、遮挡、玻璃炸裂）不在检测能力范围内；
2. **成像条件**：极端光照、夜间、雨雾、严重运动模糊或过远拍摄距离场景下，检测性能可能显著下降；
3. **置信度语义**：输出置信度为模型对检测结果的确信程度，并非缺陷真实概率；
   低置信度结果存在较高误检可能，展示阈值以下的目标不予显示（默认0.25）；
4. **漏检风险**：召回率指标基于测试集统计，实际部署中仍可能出现漏检；
   本系统定位为运维辅助工具，**不得作为安全关键决策的唯一依据**，重要结论需人工复核；
5. **数据隐私**：用户上传图像仅用于本系统检测服务，不用于模型训练或任何其他用途（PRD第7章）。
