## 2 指标基线（全文强制一致，不修改）

以下指标为任务书验收线，5 份文档中凡出现均须与此一致（来源：spec.md / checklist.md / model_eval_report.md）：

| 指标 | 数值 |
|---|---|
| mAP@0.5（测试集总体，工程+官方双口径） | ≥ 75% |
| 主要缺陷类别召回率（积灰/鸟粪/电损伤/物理损伤/积雪，conf=0.25、IoU=0.5 工程口径） | 每类 ≥ 80% |
| 单图推理耗时（CPU onnxruntime，letterbox+推理+NMS，预热多次取均值） | ≤ 200ms |
| 数据集划分 / 标注格式 | 8:1:1 / YOLO txt |
| 上传大小上限 / 格式 | 10MB / jpg、jpeg、png、bmp |
| 推理输入尺寸 / 置信度阈值 / NMS IoU | 640 / 0.25（D7）/ 0.45 |
| 检测类别 | 清洁、积灰、鸟粪、电损伤、物理损伤、积雪（6 类） |
| 模型 / 优化器 / 学习率 | yolov8s（COCO 预训练迁移）/ AdamW / lr0=0.001（D16/D17） |
| JWT 有效期 / 密码哈希 | 24h（D27）/ PBKDF2 600000 次迭代（D26） |
| 端口 / 环境变量 | 8000、5173 / PV_SECRET_KEY、PV_UPLOAD_MAX_MB、PV_IMGSZ、PV_ORT_THREADS、PV_PWD_ITERATIONS、PV_TOKEN_EXPIRE_MINUTES、VITE_API_BASE |
